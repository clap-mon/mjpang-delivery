# 럭키팡: 문장던전 (LuckyPang: Sentence Dungeon)

> **부제**: 문장 성분과 호응 관계  
> **소프트웨어 버전**: v1.0.0 (정식 배포판)  
> **적용 교육과정**: 2022 개정 초등 국어과 교육과정 (초등 3~6학년 문법 및 문해력 연계)

---

## 📖 제품 개요

**럭키팡: 문장던전**은 초등학교 3~6학년 국어 교육과정의 핵심 영역인 **[문장의 성분(주어·서술어·목적어)]**과 **[문장의 호응 관계(시간·높임·부정·까닭)]**를 자기주도적 게임화(Gamification) 환경에서 체계적으로 학습할 수 있도록 개발된 교육용 웹 애플리케이션입니다.

- **무설치·무로그인**: 별도의 회원가입이나 개인정보 수집 없이 브라우저에서 즉시 실행
- **인터랙티브 학습**: 스토리 대화, 인터랙티브 퀘스트(빈칸·연결·순서 배열), 실시간 카드 전투 퀴즈
- **학습 동기 부여**: 5단계 스테이지, 54종 성취 칭호 도감, 비민감 로컬 저장소를 통한 진행률 보존

---

## 🛠 기술 스택

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Vercel 및 정적 웹 호스팅 완벽 지원 (무서버 Serverless 구동)

---

## 🚀 시작하기 & 빌드 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속하여 즉시 테스트할 수 있습니다.

### 3. 프로덕션 빌드
```bash
npm run build
```

## 🔒 보안 응답 헤더 기본 적용 내역

본 소프트웨어는 브라우저 보안 강화 및 웹 취약점 사전 예방을 위해 호스팅 응답 헤더 6종이 프레임워크 소스 코드(`next.config.ts`)에 기본 내장되어 배포됩니다.

- `Strict-Transport-Security`: HSTS 적용 (`max-age=63072000; includeSubDomains; preload` - HTTPS 통신 강제)
- `Content-Security-Policy (CSP)`: 미인가 외부 스크립트·인라인 위험 실행 차단 및 정적 리소스 화이트리스트 보호
- `X-Content-Type-Options: nosniff`: 브라우저 MIME 타입 스니핑 방지
- `X-Frame-Options: DENY`: 외부 사이트 iframe 삽입 차단 (클릭재킹 방지)
- `Referrer-Policy: strict-origin-when-cross-origin`: 민감한 참조자 정보 노출 방지
- `Permissions-Policy`: 미사용 브라우저 디바이스 권한(카메라·마이크·위치정보 등) 접근 차단

## 🌐 시스템 운영 및 도입 기관 안내사항

### 1. 무서버(Serverless) 운영 편의성
- 별도의 백엔드 데이터베이스 구축 및 서버 유지보수 비용이 발생하지 않습니다.
- Vercel, GitHub Pages, 클라우드 스토리지(S3), 사내/학내 웹 서버 등 원하는 웹 환경에 즉시 정적 배포 가능합니다.

### 2. 호스팅 라이선스 책임 소재
- 소프트웨어 운영에 필요한 웹 도메인 및 호스팅 계정/요금제는 도입 기관(납품처)의 정책에 따라 직접 선정하고 관리합니다.
> *"본 소프트웨어 운영에 필요한 도메인 및 호스팅 계정/요금제는 도입 기관(납품처)이 직접 결정하고 관리합니다."*

### 3. 시스템 운영 관리 권고 사항
- **호스팅 계정 보안**: Vercel 등 호스팅 및 Git 계정에 2단계 다중 인증(MFA/2FA) 활성화를 권장합니다.
- **정기 보안 점검**: 소프트웨어 운영 주기 중 프레임워크 보안 업데이트 및 라이브러리 취약점 점검(`npm audit`)을 권장합니다.
